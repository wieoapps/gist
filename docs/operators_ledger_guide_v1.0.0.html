The Cold Rig

Nobody's seen the last Sysop in three weeks. What's left in the safehouse is a dead terminal, a rack that hasn't been powered down, and a note taped over the drive bay: the Gist doesn't come with a project. It never did. You don't inherit an Exchange — you have to stand one up, from a cold rig, tonight.

So you don't hand-wire a module and a manifest out of nothing. You point the rig's own binary at itself and let it build its own scaffolding.

terminal 
./bin/gist-server -new-project meridianexchange -generate-config gist-api-server
cd meridianexchange
go get github.com/wieoapps/gist-sdk

It refuses outright if a rig's already standing at that path — no clobbering somebody else's build by accident. What it hands back instead is a bare skeleton: a go.mod, a main.go that does nothing yet, and a manifest sitting at config/config.json with exactly one process already named in it — file-job, the uplink desk from the first chapter, waiting for you to give it a body. Boot the rig and gistsdk.NewApp reads that manifest without you touching a single wire. Everything from here is the same move, over and over: one more entry, one more process, until the rig is the Exchange again.
